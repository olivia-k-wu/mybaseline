# Baseline 使用指南（给没有编程背景的你）

## 先说清楚：你需要一个「会干活的 AI」

普通聊天机器人（比如豆包聊天、微信里的客服机器人）只会聊天——**不会读你电脑上的文件、不会上网拉数据、记不住上次聊了什么**。

Baseline 需要的是一个**执行型 AI**：它能读文件、跑命令、写文件，并且记得你。下面三个都行，挑一个顺手的。全程你只需要说一句话，剩下的它自己做，你**不用碰任何代码**。

## 一句话（三个载体通用）

装好下面任意一个执行型 AI 后，对它说：

> **「去 GitHub 下载并安装 https://github.com/olivia-k-wu/mybaseline。帮我分析我的持仓。」**

它会自动在 GitHub 上找到这个 skill、下载并运行。第一次使用，它会先问你几个问题（风险偏好、投资期限等），友善地引导你上传持仓截图或手动输入，然后生成一份穿透式风险分析报告。

---

## 方案一：腾讯 WorkBuddy（国内最顺，推荐）

**装什么**：去 WorkBuddy 官网下载桌面 App 并登录。用你自己的账号（支持微信/腾讯登录），**不需要 OpenAI/Anthropic 账号**，用的是国产模型。

**然后**：对 WorkBuddy 说上面那句话。

**会得到什么**：它先问你风险偏好、引导你上传持仓截图——银行 App（中国银行、招商银行等）、基金/理财平台（支付宝、天天基金等）、券商 App（中银证券、华泰证券、东方财富等）的持仓页截图都行——然后自动建好记忆文件、拉实时数据、生成报告。

---

## 方案二：豆包 MarsCode（字节生态）

**装什么**：下载「豆包 MarsCode」。（注意：是**编程工具**，不是「豆包」聊天 App。）

**然后**：对 MarsCode 说上面那句话。

**会得到什么**：同上——它读仓库里的分析流程，问你风险偏好、引导上传持仓，拉数据，出报告。

**注意**：豆包聊天 App 做不到这件事，一定要 MarsCode（编程 Agent）。

**然后**：对 Codex 说上面那句话。

**会得到什么**：同上。适合已经会用命令行、或人在海外的用户。

## 三句话搞懂它怎么工作

1. **你上传持仓** → 它写进你本地的一个文件（`portfolio.json`）
2. **它拉公开行情 + 做分析** → 穿透分析（看穿基金标签、发现「伪分散化」）+ 归因 + 市场研究 + 风险指标（夏普比率、最大回撤、相关性、再平衡）
3. **它自动记日记** → 每次分析后更新你的「投资画像」「投资记忆」「投资日记」，越用越懂你

**你的所有数据都只在你自己的电脑里，作者看不到，也互不共享。**

## 它不只是报数字，还会教你

报告里每个陌生概念，它都会用大白话讲一句——比如「伪分散化」就是「你买了 10 只基金，底层其实是同一批股票」；「再平衡」就是「涨了卖一点、跌了买一点，用纪律对抗人性」。你得到的不只是一张盈亏表，而是一份**能让你逐渐看懂自己组合为什么这样走**的投资课。
