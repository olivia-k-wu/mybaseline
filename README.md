# Baseline · 基金持仓分析方法论

一个可分享的 AI Skill：把「机构级投研框架」——穿透式风险分析、多维盈亏归因、专业市场研究——装进你本地的 AI 助手。附带一套记忆系统（投资者画像 + 投资记忆 + 投资日记），让它越用越懂你。

> ⚠️ **定位**：学习 / 研究方法论，输出仅供教育参考，不构成投资建议。

## 一句话开始

把它下载到你的 AI 助手，然后对它说：

> **「去 GitHub 下载并安装olivia-k-wu的mybaseline 帮我分析我的持仓。」**

不管用哪个载体（WorkBuddy / 豆包 MarsCode / Codex），说这一句话即可：它会自动在 GitHub 上找到这个 skill、下载并运行。第一次使用，它会先问几个关于你的问题（风险偏好、投资期限等），友善地引导你上传持仓截图或手动输入，然后拉取实时数据、生成一份穿透式风险分析报告。以后每次分析，都会自动更新你的投资日记和记忆。

## 你需要什么

一个**能读文件 + 跑命令的执行型 AI**（不是普通聊天机器人）。推荐这三个：

| 载体 | 装什么 | 适合谁 |
|------|--------|--------|
| **腾讯 WorkBuddy** | 桌面 App，免海外账号，用国产模型 | ⭐ 国内最顺 |
| **豆包 MarsCode** | 用「编程 Agent」，不是「豆包聊天」 | 字节生态 |

完整分步教程见 [`guides/user-guide.md`](guides/user-guide.md)。

## 它怎么工作

1. 你上传持仓 → 它写入 `memory/portfolio.json`
2. 它拉取公开行情 → 做穿透分析、归因、市场研究
3. 生成 HTML 报告到 `reports/`
4. 自动更新 `memory/` 里的画像、记忆、日记

**所有数据都在你本地，互不共享，作者看不到你的任何持仓。**

## 它会教你看懂什么

它不是一张数据表，而是一份「边分析边讲解」的投资课。每次报告里，这些术语都会用大白话解释清楚：

| 概念 | 一句话解释 |
|------|-----------|
| **穿透分析** | 看穿基金名字，看它底层到底买了什么股票 |
| **伪分散化** | 你以为是 10 只基金，底层其实是同一批股票，等于押注没分散 |
| **夏普比率** | 每承担一单位颠簸，能换来多少超额收益 |
| **最大回撤** | 最坏情况下，你大概会从峰值亏多少 |
| **相关性矩阵** | 哪些基金其实「同涨同跌」，分散是假的 |
| **再平衡** | 卖高买低，用纪律对抗「涨了舍不得卖、跌了不敢买」的人性 |

所以它不只是「告诉你盈亏」，而是帮你**逐渐看懂自己的组合为什么这样走**。
